
# Présentation des outils utilisés

## 1. Python

Python est un langage de programmation interprété, polyvalent et facile à apprendre. Il permet de développer différents types d'applications, notamment des applications web, des logiciels et des scripts.

## 2. Visual Studio Code (VS Code)

Visual Studio Code est un éditeur de code source développé par Microsoft. Il permet d'écrire, de modifier et de déboguer du code grâce à ses nombreuses extensions.

## 3. Git

Git est un système de gestion de versions distribué. Il permet de suivre les modifications apportées aux fichiers d'un projet, de créer des branches et de revenir à des versions précédentes.

## 4. GitHub

GitHub est une plateforme d'hébergement de dépôts Git. Elle facilite le partage de code, le travail collaboratif, le suivi des problèmes et la gestion des projets.
