
# Atelier GL - Module 1

## 1. Objectif du projet

Ce projet a été réalisé dans le cadre des travaux pratiques du module Outils et Ateliers de Génie Logiciel.

Il a pour objectif de mettre en pratique l'installation et la configuration des outils de développement, la structuration d'un projet Python, ainsi que la gestion des versions avec Git et GitHub.

## 2. Prérequis

Pour utiliser ce projet, les outils suivants doivent être installés :

- Python 3
- Visual Studio Code
- Git

## 3. Structure du projet

```text
atelier-gl-module1/
├── src/
│   └── main.py
├── docs/
│   └── outils.md
├── tests/
├── README.md
└── .gitignore
```

## 4. Exécution du programme

Depuis le répertoire principal du projet, exécuter la commande :

```bash
python src/main.py
```

Le programme affiche un message de bienvenue dans le terminal.
